# おとループ (sound-looper)

子ども向けワークショップ用の、シンプルで直感的な録音・ループ再生Webアプリケーションです。
スマートフォン（iPhone Safari / Android Chrome）のブラウザからアクセスするだけで、手軽に環境音や声を録音し、継ぎ目のない完全ループで空間に音を重ね合わせることができます。

---

## 主な特徴

- **完全単一ファイル構成**: `index.html` 1枚のみで完結。外部ライブラリやCDNに依存せず、軽量かつオフライン耐性があります。
- **トグル式録音操作**: 「おとをとる」ボタンを1回タップして録音開始、もう一度タップで停止。最大10秒で自動停止するセーフティ設計。
- **Web Audio APIによる完全シームレスループ**: `<audio>` タグ特有の継ぎ目ノイズ（ギャップ）を排除し、PCM波形としてループ再生。
- **クリックノイズ自動除去**: 録音音声の始点と終点にマイクロフェード（5ms）を自動適用。途中で切れた音でも「プチッ」というノイズが発生しません。
- **画面消灯（スリープ）防止**: 再生中は Wake Lock API を使用して画面ロックを防止（対応端末）。
- **子ども・保護者向けUI**: ひらがな主体の大きな文字と、絵文字を用いない明瞭な幾何学アイコン・色彩設計。

## サーバーへの設置方法

ご自身のWebサーバーの公開ディレクトリに `index.html` をアップロードするだけで稼働します。

### 必須要件
- **HTTPS環境であること**:
  スマートフォンのブラウザ（iOS Safari / Android Chrome）でマイク録音（`navigator.mediaDevices.getUserMedia`）を利用するためには、SSL/HTTPSでの配信が必須です（`http://` ではマイク機能が動作しません）。

### 配置手順の例
1. サーバーの公開領域（例: `/var/www/html/loop/` やレンタルサーバーの `public_html/loop/`）にディレクトリを作成します。
2. そのディレクトリ直下に本リポジトリの `index.html` を配置します。
3. `https://your-domain.com/loop/` でアクセスできることを確認します。

## ワークショップ当日の運用ポイント

1. **QRコードの準備**:
   - 会場内の各席にURLのQRコードを印刷して配布するか、プロジェクターで投影しておくとスムーズに開始できます。
2. **iPhoneのマナーモード・音量確認**:
   - iPhoneの物理サイレントスイッチ（マナーモード）がオンになっていてもWeb Audio APIからの音声は出力されますが、端末本体の音量設定が最小になっていないか事前に保護者へお声がけください。
3. **マイクアクセスの許可**:
   - 初回タップ時にブラウザから「マイクの使用を求めています」というダイアログが表示されます。「許可」を選択するよう促してください。
